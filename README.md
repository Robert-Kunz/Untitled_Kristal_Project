# The (currently) untitled kristal project
So, this is and probably will be an ongoing project about making my own deltarune mod using the kristal fan engine. This will be updated periodically and will probably have a slow pace. These updates usually drop something finished unless i notice something else afterwards that i did wrong or wanted to change.

## Save File Names and what they do (or will do)
Names of the main Partymembers (SD/SUSHIDIEB, HW/HONEYWISP, FIFTY/50/50SET80) - Activates a challenge run where you only have the respective party member and at the start a toggle to remove temporary party members (it also alters the main story to fit the solo run!)
RANDOM/EGGY/FIFTYSET80/PEACHY/MACC/MACCPRO/MINTYMORON/SEMANTICS - Give a specific reaction from mystery man at the start and give specific interactions later on
WDGASTER/GASTER - Give a specific reaction from mystery man at the start
ROBERT (that's meeeee) - gives a specific reaction from mystery man at the start
DEBUG - skips the starting cutscene
Any other name - Nothing special
